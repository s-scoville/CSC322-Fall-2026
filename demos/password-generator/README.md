# React Password Generator

A customizable password generator built with React 19 and Vite for my CSC322 Web Programming portfolio.

## Features

- Generate random passwords between 8 and 32 characters.
- Choose uppercase letters, lowercase letters, numbers, and symbols.
- Include at least one character from each selected category.
- Generate passwords using the browser's Web Crypto API.
- Copy generated passwords to the clipboard.
- Responsive interface with validation and status messages.

## Development

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

## Technologies

- React 19
- JavaScript (JSX)
- Vite
- HTML/CSS
- Web Crypto API
